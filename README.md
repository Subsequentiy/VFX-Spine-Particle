# VFX Spine Particle

一个**单文件、纯前端、完全离线**的特效素材工具：把一张精灵表（sprite sheet）按
行 × 列切成矩形切片，依次套上去黑、调色、极坐标、锐化、径向模糊、曲线等效果，
然后导出成序列帧 / Spine 骨骼动画；另带一个可单独使用的**粒子编辑器**。

> **在线使用**：<https://subsequentiy.github.io/VFX-Spine-Particle/>
> （建议用 Chrome 或 Edge 打开，原因见下面「浏览器要求」）

---

## 这是什么

做 2D 特效常遇到的活：手里只有一张拼好的图集，需要把它拆成一张张图，
再导进 Spine / Cocos / Unity 里做成动画。这个工具把这些步骤放进一个网页里，
打开即用、不装软件、不传服务器。

整个程序就是**一个 HTML 文件**，样式和全部脚本（约一万八千行）都内联在里面，
不加载任何 CDN、字体或第三方库，断网也能正常工作。所有图片处理都在你自己的浏览器里完成，
**不会上传到任何服务器**。

## 功能

**四个页面，从顶栏切换：**

| 页面 | 作用 |
| --- | --- |
| **网格** | 导入整张图 → 自动 / 手动定行列 → 切片预览 → 导出序列帧或 Spine |
| **VFX** | 把多张序列帧图拼成一段动画，预览后导出序列帧 / Spine flipbook |
| **UV** | UV 滚动贴图：多图层、遮罩、流速方向、循环帧数，导出序列帧或 Spine |
| **粒子** | 独立的粒子编辑器：发射器形状、生命曲线、重力 / 风 / 阻力 / 噪波，导出 Spine |

**其它**

- **自动识别行列**：从图里猜出网格（透明间隔 / 背景间隔都能认），带置信度提示
- **六种像素效果**：去黑（UnMult）、色相 / 饱和度、极坐标、锐化、径向模糊、曲线
- **完整撤销 / 重做**：`Ctrl+Z` / `Ctrl+Shift+Z` / `Ctrl+Y`
- **导出 Spine**：3.8 / 4.0 / 4.1 / 4.2 四个版本可选
- **直接写入文件夹**：支持 File System Access 的浏览器可以把 PNG 直接写到你选的目录，
  否则退回到打包 zip 下载

## 浏览器要求

| 浏览器 | 使用体验 |
| --- | --- |
| **Chrome / Edge** | ✅ 完整功能，可以把文件直接写进你选的文件夹 |
| Firefox / Safari | ⚠️ 可以打开和编辑，但**不能直接写文件夹**；只有 UV 序列帧能打包 zip 下载，其余导出拿不到文件 |

所以推荐用 **Chrome 或 Edge**。

## 本地运行

三种方式，任选：

1. **直接用浏览器打开** `docs/index.html`（或发行包里的 html）。能用，但 `file://`
   下浏览器禁用了「选择文件夹」，导出只能走下载 / zip。
2. **起一个本地静态服务**（推荐本地使用）：
   ```bash
   # 任意静态服务器都行，例如
   npx serve docs
   ```
   然后访问终端里给出的地址。此时是用 `http://localhost` 打开，属「安全上下文」，
   可以直接选文件夹导出。
3. **直接用在线版**：<https://subsequentiy.github.io/VFX-Spine-Particle/>

## 仓库结构

```
.
├─ docs/                 ← GitHub Pages 发布目录
│  ├─ index.html         ← 程序本体（就是全部源码）
│  ├─ 404.html           ← 地址打错时的提示页
│  └─ .nojekyll          ← 关掉 Jekyll 处理
└─ README.md
```

整个工具只有 `docs/index.html` 一个文件，约 757 KB。想看源码直接打开它，
样式在 `<style>` 里、逻辑在文件末尾那几段 `<script>` 里（都排过序、带中文注释）。


## 说明

- 本工具**不写入** localStorage / IndexedDB / Cookie，关掉页面即清空，不留痕。
- 图片全程只在浏览器内存里处理，没有任何上传行为。
- 页面内的「输出文件夹」在当前站点上会显示「未选择」——线上没有本地服务，
  需要你自己点一下选择目录，或者走下载。
